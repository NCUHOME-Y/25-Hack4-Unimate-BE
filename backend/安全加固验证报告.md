## ⚠️ 已知问题和建议

### 1. HTTPS未启用 (生产环境必须)
**风险**: HTTP明文传输
**建议**: 
```nginx
# nginx配置
server {
    listen 443 ssl http2;
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location / {
        proxy_pass http://localhost:8080;
    }
}
```

### 2. localStorage存储Token
**风险**: XSS攻击可读取
**建议**: 改用httpOnly Cookie

### 3. 缺少监控告警
**建议**: 
- 接入Prometheus/Grafana
- 设置登录失败告警
- API响应时间监控
